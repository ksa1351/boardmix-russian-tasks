Подсказка
Действительное причастие настоящего времени
Условие и основа
НСВ → форма 3-го лица мн. ч. → основа настоящего времени.читать → читают → чита-
Спряжение
I: -ут/-ют
II: -ат/-ятчитают → I спр.
Суффикс
I → -ущ-/-ющ-
II → -ащ-/-ящ-чита- + -ющ- → читающий
Исключения: I спр. — брить, стелить; II спр. — гнать, держать, дышать, слышать, смотреть, видеть, ненавидеть, обидеть, зависеть, терпеть, вертеть.
Действительное причастие прошедшего времени
Основа
Поставь глагол в прошедшее время и выдели основу прошедшего времени.прочитал → прочита-
нёс → нёс-
Выбор суффикса
Основа на гласный → -вш-
Основа на согласный → -ш-.
Сборкапрочита- + -вш- → прочитавший
нёс- + -ш- → нёсший
Если основа инфинитива и прошедшего времени различается, ориентируйся на форму прошедшего времени: нести → нёс → нёсший.
Страдательное причастие настоящего времени
Условия и основа
НСВ + переходный глагол → основа настоящего времени.проверяем → проверя-
храним → хран-
Спряжение
I спр. → -ем-
II спр. → -им-.
Сборкапроверя- + -ем- → проверяемый
хран- + -им- → хранимый
Даже у формально подходящего глагола страдательное причастие настоящего времени образуется не всегда. Если формы нет — выбери «Не образуется».
Страдательное причастие прошедшего времени
Проверь и найди основу
Обычно нужен переходный глагол. Выдели основу.прочитать → прочита-
решить → реш-
закрыть → закры-
Суффиксы
-нн- · -енн-/-ённ- · -т--ать → -анный
-ять → -янный
Сборкапрочита- + -нн- → прочитанный
реш- + -ённ- → решённый
закры- + -т- → закрытый
Страдательное причастие прошедшего времени образуется не от каждого переходного глагола. Если нормативной формы нет — выбери «Не образуется».

Памятка: маршрут образования причастия

1. Исходный глагол.
Определи, от какого глагола образуется форма.
2. Настоящее время?
Оно возможно только у глагола НСВ.
3. Страдательное?
Проверь переходность исходного глагола.
4. Действительное настоящее.
I → -ущ-/-ющ- · II → -ащ-/-ящ-.
5. Страдательное настоящее.
I → -ем- · II → -им-.
6. Действительное прошедшее.
Основа на гласный → -вш- · на согласный → -ш-.
7. Страдательное прошедшее.
-нн- · -енн-/-ённ- · -т-.
8. Краткое страдательное прошедшего.
В краткой форме пишется одна Н.
